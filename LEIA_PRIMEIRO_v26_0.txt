GMV GESTÃO v26.0 — BACKUP INTELIGENTE

COMO FUNCIONA
- Todos os lançamentos são salvos primeiro no próprio aparelho.
- O sistema tenta fazer backup automático às 09:00 e às 18:00.
- Se estiver sem internet, os dados continuam salvos e serão enviados quando a conexão voltar.
- O botão “Fazer backup agora” envia e recebe as novidades manualmente.
- O botão “Backup” continua gerando um arquivo JSON para guardar no computador ou telefone.

IMPORTANTE SOBRE IPHONE
Um site não consegue acordar sozinho em horário exato quando está totalmente fechado. Por isso:
- Se o GMV estiver aberto às 09:00 ou 18:00, o backup começa automaticamente.
- Se estiver fechado, o sistema faz o backup atrasado quando for aberto novamente ou quando a internet voltar.

SEGURANÇA
- Não há sincronização em tempo real.
- Não há repetição contínua de gravações.
- Somente registros novos ou alterados são enviados.
- Dados vazios da nuvem não apagam os dados do aparelho.
